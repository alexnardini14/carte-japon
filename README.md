# Carte PVT Japon

Carte perso pour le PVT au Japon (sept. 2027 → mai 2028) : restos, activités, shopping, hôtels, location de voiture, Reels, et la checklist des démarches.

- `data/places.json` : tous les lieux (catégorie, sous-catégorie, note, lien Google Maps).
- `data/checklist.json` : la checklist PVT (d'après le guide des pvtistes).
- `data/trip.json` : réservé à l'itinéraire (vide pour l'instant).
- `config.js` : la clé publique Mapbox.

Hébergé gratuitement avec GitHub Pages. À ajouter sur l'écran d'accueil du téléphone (Partager → « Sur l'écran d'accueil »).
